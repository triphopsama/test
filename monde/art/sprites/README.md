# Sprites (essai)

Pixel art généré par code (`generer_sprites.py`, Python + Pillow), 16 × 24 pixels par image.

- `*_planche.png` : une planche par personnage, prête pour Godot (AnimatedSprite2D / SpriteFrames). 4 colonnes = 4 images de marche (immobile, pas gauche, immobile, pas droit) ; 4 lignes = bas, gauche, droite, haut.
- `apercu_marche.gif` : aperçu animé, agrandi ×6, sur de l'herbe.
- `planches_x6.png` : toutes les planches agrandies.

Personnages : villageois, Mara (boulangère), Nina (renarde : oreilles et queue), Pierrick (demi-elfe). Les couleurs sont une palette par personnage ; une nouvelle variante = une nouvelle palette.
